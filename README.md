# Social Engineering Awareness - Interactive Web Simulations

This repository contains a collection of interactive web applications designed for Security Awareness Training. The goal is to educate teenagers and adults about the dangers of social engineering in a practical and engaging way.

## 🚀 The Simulations

The project consists of four modules, simulating different attack vectors:

### 1. Fake Bank Call (Audio Simulation)
A simulation of a fraudulent phone call from a purported bank.
*   **Features:** Utilizes the **Web Speech API** (Browser Text-to-Speech) to generate a dynamic audio simulation. Users must identify red flags (time pressure, fear-mongering, TAN requests) and choose the correct reaction.
*   **Focus:** Identifying Voice Phishing (Vishing).

### 2. Email Phishing (Bank Login)
A classic phishing email demanding an urgent login.
*   **Features:** An interactive mini-scenario with decision trees. Users learn to identify suspicious domains, time pressure, and vague salutations.
*   **Focus:** Spotting phishing emails and reacting safely.

### 3. SMS / WhatsApp Scam (Package Smishing)
A realistic simulation of a fake package delivery notification on a smartphone.
*   **Features:** A visual "Phone-UI" simulates a chat message. The user must recognize that a small fee (€1.99) and a strange domain are typical characteristics of smishing (SMS phishing).
*   **Focus:** Recognizing scam SMS and protecting personal data.

### 4. Interactive Learning Page (General)
An overview page that explains the psychological tricks (pressure, authority, emotions) and provides instructions for what to do in an emergency (e.g., if one has already clicked).

## 🛠️ Technologies Used
*   **HTML5:** Semantic structure of the simulations.
*   **CSS3:** Modern, dark-mode UI design, Responsive Web Design (Mobile First), CSS variables for consistent theming.
*   **Vanilla JavaScript:**
    *   Dynamic UI rendering.
    *   State management (scoring system).
    *   Integration of the **Web Speech API** (Text-to-Speech) for the audio simulation.
    *   Event handling for interactive quiz elements.

## 🎯 Learning Objectives & Motivation
Social engineering is one of the biggest threats to IT security. Many people fall for these tricks because they are under stress or simply don't know the techniques. 
My motivation for this project was to create a **low-threshold, interactive learning environment** that works without installation and can be used directly in a browser (e.g., in a classroom or at a parent-teacher evening).
